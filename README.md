# Яндекс Диск для Linux (ydx)

Неофициальный настольный клиент Яндекс.Диска в духе Windows-приложения:
полноценный файловый браузер, публичные ссылки, корзина, фотогалерея,
очередь передач и управление официальным демоном `yandex-disk`.

**Неофициальный клиент. Не связан с Яндексом.**

## Возможности

- Разделы: Файлы, Недавние, Фото (галерея + полноэкранный просмотр), Общие
  (публичные ссылки), Загрузки (очередь передач), Корзина (восстановление)
- Загрузка/скачивание с прогрессом, паузой и отменой; drag&drop
- Публичные ссылки (publish/unpublish) с копированием в буфер
- Тёмная/светлая тема, интерфейс RU/EN
- Управление демоном `yandex-disk` (старт/стоп, выборочная синхронизация,
  read-only) — опционально, приложение полноценно работает и без него
- До 2 аккаунтов

## Установка

```bash
sudo apt install -y python3-venv libegl1 libgl1 libxkbcommon0 libfontconfig1 libglib2.0-0t64 libdbus-1-3
./install.sh
./run.sh
```

Ярлык в меню: `cp yandex-disk-linux.desktop ~/.local/share/applications/`

## Регистрация OAuth-приложения (один раз, ~5 минут)

Для входа нужен свой OAuth-ключ Яндекса:

1. Откройте **https://oauth.yandex.ru/client/new/** и войдите в аккаунт.
2. Название — любое (например, «Мой диск-клиент»).
3. Платформа: **«Веб-сервисы»**. В поле Redirect URI вставьте:
   ```
   http://localhost:8917
   ```
   (нужно только для входа «через браузер»; для входа по коду устройства
   redirect не требуется, но поле лучше заполнить)
4. Доступы: **Яндекс Диск REST API** → отметьте
   - `cloud_api:disk.read`
   - `cloud_api:disk.write`
   - `cloud_api:disk.info`
   - `cloud_api:disk.app_folder`
5. Нажмите «Создать приложение» и скопируйте **ClientID** и **ClientSecret**
   со страницы приложения.
6. При первом запуске клиента вставьте их на странице входа.

Способы входа:
- **По коду устройства** (проще всего): приложение покажет код — откройте
  `https://oauth.yandex.ru/device`, введите код и подтвердите.
- **Через браузер**: откроется Яндекс ID, ответ вернётся на `localhost:8917`.
- **Вставка токена**: если OAuth-токен уже есть (права `cloud_api:disk.*`).

Токены хранятся в GNOME Keyring (libsecret); если он недоступен — в файле
`~/.config/yandex-disk-linux/tokens.json` с правами 0600 (приложение предупредит).

## Запуск и разработка

```bash
./run.sh                          # запуск приложения
QT_QPA_PLATFORM=offscreen ./venv/bin/python3 -m pytest tests/ -q   # тесты
```

Структура: `ydx/core` (REST/OAuth, без Qt) · `ydx/services` (настройки, аккаунты,
превью, i18n) · `ydx/ui` (окна и виджеты) · `tests`.

Каталоги данных: `~/.config/yandex-disk-linux/`, `~/.cache/yandex-disk-linux/`.

## Известные ограничения

- С июня 2026 двусторонняя синхронизация через официальный демон требует
  подписку Яндекс 360; REST-функции (файлы, ссылки, корзина, фото) работают
  на бесплатных аккаунтах.
- Лимит загрузки через API: 1 ГБ на файл без подписки.
- Скриншоты/заметки из Windows-клиента не реализованы.
